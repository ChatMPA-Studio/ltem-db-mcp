# MCP Development Tutorials

Step-by-step guides for building MCP servers from this template.

## Quick Start Series

These tutorials walk you through creating a complete MCP server:

1. **[Setup New MCP](quick-01-setup-new-mcp.md)** - Copy template and customize for your domain
2. **[Create First Tool](quick-02-first-tool.md)** - Build your first MCP tool with database queries
3. **[Add MCP Resources](quick-03-mcp-resources.md)** - Expose schema and documentation as resources
4. **[Statistical Tools](quick-04-statistical-tools.md)** - Add scipy/numpy statistical analysis
5. **[Analysis Skills](quick-05-analysis-skills.md)** - Create multi-step analysis workflows
6. **[Security Configuration](quick-06-security-config.md)** - Implement table whitelists and read-only access
7. **[Docker Deployment](quick-07-docker-deployment.md)** - Deploy with Docker and Caddy reverse proxy
8. **[Testing MCP](quick-08-testing-mcp.md)** - Write comprehensive tests for your MCP

## Prerequisites

- Python 3.10+
- MySQL or PostgreSQL database
- Docker (for deployment tutorials)
- Basic understanding of SQL and Python

## Tutorial Format

Each tutorial includes:
- **Learning objectives** - What you'll accomplish
- **Prerequisites** - What you need before starting
- **Step-by-step instructions** - Detailed walkthrough with code
- **Testing** - How to verify it works
- **Troubleshooting** - Common issues and solutions
- **Next steps** - Where to go from here

## Estimated Time

- **Individual tutorials:** 30-60 minutes each
- **Complete series:** 6-8 hours total
